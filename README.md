**RoboClicker** — незавершённая браузерная clicker-игра о развитии космической лаборатории и армии роботов.

Игрок нажимает на центрального робота, получает золото, улучшает силу клика, покупает автоматических роботов, открывает скины, использует усиления и выполняет достижения.

> [!WARNING]
> Проект находится в разработке и не выпускался в релиз.
>
> Некоторые функции могут быть незавершёнными, работать нестабильно или требовать дополнительной настройки. Текущую версию не следует считать готовым коммерческим продуктом.

## Об игре

По сюжету игрок становится главным инженером секретной космической лаборатории будущего.

Основная задача — развивать производство золота и усиливать своего робота.

Основной игровой цикл:

1. Нажимать на робота.
2. Получать золото.
3. Улучшать силу клика.
4. Покупать автоматических роботов.
5. Увеличивать пассивный доход.
6. Повышать уровень инженера.
7. Покупать и открывать скины.
8. Использовать временные и постоянные усиления.
9. Выполнять достижения.
10. Возвращаться в игру и продолжать развитие.

## Игровой процесс

### Получение золота

Главный способ получения золота — нажатие на центрального робота.

Количество золота за одно нажатие зависит от текущей силы клика и активных бонусов.

Полученное золото можно использовать для:

* улучшения клика;
* покупки автоматических роботов;
* покупки скинов;
* покупки и улучшения бустов.

### Сила клика

Улучшение клика увеличивает количество золота, которое игрок получает за одно нажатие.

После каждой покупки:

* сила клика увеличивается;
* стоимость следующего улучшения возрастает;
* прогресс сохраняется в браузере;
* обновляется игровая статистика;
* может измениться прогресс достижений.

### Автоматические роботы

Автоматические роботы создают пассивный доход.

Игрок получает золото автоматически, даже если не нажимает на центральный объект.

Покупка роботов влияет на:

* количество роботов;
* доход в секунду;
* стоимость следующего робота;
* общий заработок;
* офлайн-доход;
* достижения.

### Уровни

Игрок начинает с нулевого уровня.

Для перехода на следующий уровень необходимо совершать клики и заполнять шкалу прогресса.

Первый переход уровня требует установленного количества кликов. Требования к каждому следующему уровню постепенно увеличиваются.

Уровень используется для:

* отображения общего прогресса;
* открытия некоторых функций;
* выполнения достижений;
* получения дополнительных целей;
* развития игровой экономики.

## Бусты

Усиления разделены на три категории:

### Временные

Действуют ограниченное время.

Примеры эффектов:

* увеличение силы клика;
* ускорение офлайн-дохода;
* увеличение дохода роботов;
* дополнительное золото за клик;
* мгновенное получение монет;
* усиление следующего клика;
* скидка на следующую покупку.

### Постоянные

После покупки постоянно улучшают характеристики игрока.

Примеры:

* дополнительная сила клика;
* увеличение дохода роботов;
* бонус за уровень;
* увеличение общего дохода.

### Супербусты

Создают сильный временный эффект.

Примеры:

* критический перегруз;
* заморозка времени;
* галактический прорыв;
* омега-режим.

Стоимость, продолжительность и баланс усилений не являются окончательными.

Условия могут зависеть от:

* количества кликов;
* общего заработанного золота;
* количества роботов;
* числа улучшений клика;
* уровня игрока;
* купленных скинов;
* использованных усилений;
* одновременно активных бустов;
* выполнения нескольких условий;
* общего прогресса игрока.

Примеры достижений:

* сделать первый клик;
* купить первого робота;
* впервые улучшить силу клика;
* достигнуть определённого уровня;
* заработать установленное количество золота;
* купить несколько роботов;
* совершить тысячи или миллионы кликов;
* открыть редкие скины;
* использовать разные типы бустов;
* активировать несколько усилений одновременно;
* получить остальные достижения.

За выполнение достижения игрок может получить:

* золото;
* специальный бонус;
* новый скин;
* постоянное улучшение.

Корректность всех достижений и их условий требует отдельного тестирования.

## Настройки

### Язык

Интерфейс поддерживает:

* русский язык;
* английский язык.

Некоторые тексты могут быть переведены не полностью.

### Громкость

В настройках предусмотрен ползунок общей громкости.

Он управляет звуковыми эффектами игры.

### Яркость

В игре предусмотрена программная настройка яркости интерфейса.

Она изменяет яркость страницы игры, но не системную яркость экрана устройства.

### Тема

Доступны три режима:

* тёмная;
* светлая;
* автоматическая.

Автоматическая тема может зависеть от системных настроек пользователя.

### Сброс прогресса

Игрок может удалить весь игровой прогресс через настройки.

Сброс может удалить:

* золото;
* силу клика;
* роботов;
* уровни;
* открытые скины;
* выбранный скин;
* бусты;
* достижения;
* игровую статистику;
* пользовательские настройки.

Операцию сброса невозможно отменить без резервной копии.

## Офлайн-доход

Проект хранит время последнего запуска и может рассчитывать доход, созданный роботами за время отсутствия игрока.

Офлайн-доход зависит от:

* числа роботов;
* текущего дохода в секунду;
* времени отсутствия;
* постоянных бонусов;
* временных усилений;
* корректности сохранённых данных.

Эта функция требует проверки на длительных периодах отсутствия и при изменении системного времени.

## Локальный запуск

### Способ 1. Python

Откройте терминал в папке проекта:

```bash
python -m http.server 8000
```

После запуска откройте:

```text
http://localhost:8000
```

В некоторых системах используется команда:

```bash
python3 -m http.server 8000
```

### Способ 2. Visual Studio Code

Можно использовать расширение Live Server:

1. Открыть папку проекта в Visual Studio Code.
2. Нажать правой кнопкой мыши по `index.html`.
3. Выбрать `Open with Live Server`.
4. Открыть показанный адрес в браузере.

### Способ 3. Node.js

При установленном Node.js:

```bash
npx serve .
```

### Прямое открытие

Файл `index.html` можно открыть двойным нажатием.

Однако при запуске через протокол `file://` некоторые браузерные и платформенные функции могут работать иначе.

Для разработки рекомендуется локальный HTTP-сервер.

## Проверка JavaScript

При установленном Node.js можно проверить синтаксис:

```bash
node --check script.js
```

Если команда не вывела ошибок, JavaScript прошёл базовую синтаксическую проверку.

## Возможные проблемы

### Игра открывается без оформления

Проверьте наличие файла:

```text
style.css
```

В `index.html` должно быть подключение:

```html
<link rel="stylesheet" href="style.css">
```

### Кнопки не работают

Проверьте наличие файла:

```text
script.js
```

Также убедитесь, что скрипт подключён в `index.html`.

### Не воспроизводится звук

Проверьте наличие:

```text
click.wav
menu.wav
start.wav
```

Также убедитесь, что:

* звук не выключен в настройках;
* вкладка браузера не заглушена;
* громкость устройства включена;
* пользователь хотя бы один раз взаимодействовал со страницей.

### Не сохраняется прогресс

Возможные причины:

* запрещён доступ к `localStorage`;
* используется приватный режим;
* браузер очищает данные после закрытия;
* закончилось доступное место;
* страница запускается в ограниченном окружении.

### Не работает Yandex Games SDK

SDK может быть недоступен при обычном локальном запуске.

Платформенные функции необходимо проверять в окружении Yandex Games.

### Игра показывает старую версию

Выполните принудительное обновление:

```text
Ctrl + F5
```

Также можно очистить кеш браузера.
